# 牛马

面向 Apple Silicon Mac 的原生圆形时间进度小组件。默认按 `09:00–18:00` 自动计算，不需要手动开始。

## 功能

- `40–88px` 圆形悬浮组件，始终置顶并可自由拖动
- 300° 开口轨道显示时间进度，连续线表示完成、虚线表示未完成
- 进度末端使用定位点，中央独立核心默认显示“牛马”
- 定位点严格居中于轨道，并支持独立颜色与 `3–18px` 直径调节
- 大尺寸定位点会自动扩展透明窗口边界，避免在任何组件尺寸下被裁切
- 鼠标移入圆圈时，中央文案轻轻向两侧收起，简短剩余时间在中间出现
- 工作时剩余最后一分钟，核心区固定显示 `60` 至 `1`；数字每秒放大弹回，同形状淡影向外扩散；结束后显示“下班”
- “牛马”和完成后的“下班”均可自定义，并可分别调整文字颜色（默认工作紫、完成绿）
- 双击圆圈打开设置；通过菜单栏可显示、隐藏或退出
- 菜单栏同步显示精确剩余时间
- 自定义开始/结束时间，支持跨夜时间段
- 1 小时、10 分钟和 1 分钟等短时段均按秒精确推进；隐藏秒数时剩余分钟不会提前归零
- 可分别调整已完成进度、未完成轨道的颜色与轨道透明度
- 已完成进度和未完成轨道支持独立透明度，并可一键恢复默认外观
- 可自由选择背景颜色和背景透明度，悬浮文字与倒计时使用醒目的圆角粗体
- 原生 SwiftUI + AppKit，无图片、第三方库或额外后台任务

## 构建

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open dist/牛马.app
```

开发时也可以直接运行：

```bash
swift run FloatProgress
```

系统要求：macOS 14 或更高版本，Apple Silicon（M1/M2/M3/M4/M5…）。
