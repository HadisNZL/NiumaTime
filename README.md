# 牛马

同时支持 Apple Silicon 与 Intel Mac 的原生牛形倒计时小组件。默认按 `09:00–18:00` 自动计算，不需要手动开始。

## 功能

- 纯牛脸倒计时：默认显示牛耳朵，左耳显示剩余小时、右耳显示剩余分钟；可隐藏双耳
- 左额头有一块随现有点缀色变化的静态牛斑，不增加图片、动画或设置项
- 有耳朵时采用“左耳小时、右耳分钟、悬停核心显示秒”的三段式倒计时；待命时耳朵平时显示开始时间，悬停后临时显示剩余时分
- 隐藏耳朵时采用紧凑倒计时：一小时以上显示 `HH:MM`，一小时内显示 `MM:SS`，最后一分钟进入大号秒数动画；休息和完成后收起耳朵数字
- 默认尺寸 `62px`，可调 `40–88px`；悬浮窗会随双耳显隐收放并留足描边余量，可自由拖动
- 牛头不是机械等比缩放：小尺寸会强化轮廓、眼睛、鼻孔和文字，大尺寸会主动增加留白并抑制五官膨胀；细小标记按屏幕物理像素对齐，尺寸调节过程连续无跳变
- 双耳数字仅在数值变化时轻弹；完成后数字收起、牛脸变为完成态表情与颜色
- 工作时剩余最后一分钟，耳朵保留造型并收起数字，核心区独占显示 `60` 至 `1`；数字每秒放大弹回，同形状淡影向外扩散；结束后显示“下班”
- 待命时默认显示“待命”，工作中显示“牛马”，完成后显示“下班”；三种文案和文字颜色分别可调（待命与工作默认紫、完成默认绿）
- 双击悬浮组件打开设置；可锁定位置避免误拖，通过菜单栏可显示、隐藏、锁定或退出
- 菜单栏可开启“今天休息”：当天隐藏耳朵时间、显示休息牛脸；普通计划次日自动恢复，跨夜计划会休息至本次班次结束，也可随时取消，不改起止时间
- 内置中国智能工作日：内置 2024–2026 年国务院节假日与调休安排，普通周末和官方放假日自动休息，调休周末正常运行；无需开关、读取系统日历、联网或申请隐私权限
- 智能工作日支持临时覆盖：休息日菜单显示“今天上班”，工作日仍可选择“今天休息”；跨夜班按班次开始日期判断，不会在午夜被周末或节假日截断
- 尚未内置安排的年份只按普通星期规则运行，并在设置中明确提示调休数据未内置，不猜测未发布的官方安排
- 菜单栏使用代码绘制的专属单色工作牛头图标，自动适配深浅模式；倒计时使用一次缓存的等宽数字字体，秒数变化时不会左右抖动
- 自定义开始/结束时间，支持跨夜时间段；两者相同时明确按连续 24 小时的全天计划计算
- 设置顶部可用一头牛切换预览等待、工作、临近、完成四种表情；下方同步显示对应时间段或时间点，预览不修改时间段
- 1 小时、10 分钟和 1 分钟等短时段均按秒精确推进；隐藏秒数时剩余分钟不会提前归零
- 可自由调整牛头底色、牛角与面部点缀（默认紫色，另有橙红、深青、石板蓝三个快捷色）、整个组件的透明度和文字颜色，并可一键恢复默认外观
- 当自定义文字或点缀与牛头底色过于接近时，设置页会给出可读性提醒，但不会强制改变配色
- 牛的眼神和耳朵会随等待、工作、最后五分钟和完成状态轻微变化；仅在状态切换时动画，并完整遵循系统“减少动态效果”设置
- 自动适配系统“增强对比度”和“减少透明度”：增强对比度时强化轮廓与五官；减少透明度时临时强制悬浮牛完全不透明，但不会改写用户保存的透明度
- 支持登录时自动启动；显示器、分辨率或组件尺寸变化后会自动把窗口留在可见区域
- 从睡眠唤醒、跨日以及系统时间或时区变化后会立即重新校准；使用系统通知，不增加轮询任务
- 启动时会一次性校验时间、尺寸、透明度、颜色和自定义文案，自动修复越界设置；内置设置版本迁移，不增加常驻内存
- 菜单栏提供“关于牛马”，设置页显示版本与构建号
- 定时器会根据显示秒数、悬停和最后一分钟自动切换刷新频率，其余时间只在分钟边界或状态节点唤醒
- 原生 SwiftUI + AppKit，无图片、第三方库、日历权限或额外后台任务

## 构建

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open dist/牛马.app
```

构建脚本会生成一个同时包含 `arm64` 与 `x86_64` 的 Universal 应用，以及单一分发包 `dist/牛马-macOS-Universal.zip`。macOS 运行时只加载当前芯片对应的代码，不会因为通用架构增加运行内存。

默认产物使用本机临时签名，适合本机运行。公开分发时可复用同一脚本完成 Developer ID 签名与 Apple 公证（需先在钥匙串安装证书并创建 `notarytool` 凭据）：

```bash
CODESIGN_IDENTITY="Developer ID Application: 你的名称 (TEAMID)" \
NOTARY_PROFILE="牛马-notary" \
BUNDLE_ID="你的反向域名.NiumaTime" \
./scripts/build-app.sh
```

开发时也可以直接运行：

```bash
swift run FloatProgress
```

## 更新中国工作日数据

App 运行时只读取编译进二进制的紧凑日期集合，不联网、不解析 JSON。节假日数据采用手动维护：国务院公布下一年度安排，并且 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) 已收录对应年份后，在开发机更新、验证并重新发布 App。

以下以新增 2027 年数据为例。先进入项目目录，再运行更新脚本：

```bash
cd /Users/niuzilin/workProgress
./scripts/update-china-workdays.swift 2024...2027
```

脚本会下载指定年份的数据，校验年份、日期和公告来源，然后重新生成 `Sources/FloatProgress/ChinaWorkdayData.generated.swift`。新增年份时必须同时传入需要保留的全部连续年份，不能只传入新增年份。

检查生成结果并完成测试、打包：

```bash
git diff -- Sources/FloatProgress/ChinaWorkdayData.generated.swift
swift test --disable-sandbox
./scripts/build-app.sh
open dist/牛马.app
```

确认日期与国务院公告一致、测试通过且 App 运行正常后，提交并推送：

```bash
git status --short
git add -A
git commit -m "更新 2027 年中国节假日安排"
git push origin main
```

新安装包位于 `dist/牛马-macOS-Universal.zip`。内置数据更新后必须重新打包并发布，已经安装的旧版本不会自动获得新数据。整个更新过程只发生在开发机，不会给用户端增加网络请求、缓存文件、后台任务或常驻内存。

离线检查本地 JSON 时可使用：

```bash
./scripts/update-china-workdays.swift 2024...2026 --input-directory /path/to/holiday-cn
```

系统要求：macOS 14 或更高版本；支持 Apple Silicon（M1/M2/M3/M4/M5…）与 Intel 芯片。
